# onlinemidiplayer.top static assets

Files here are served to visitors of [onlinemidiplayer.top](https://onlinemidiplayer.top) via `raw.githubusercontent.com` (CORS-enabled).

- `FluidR3Mono_GM.sf3` — the General MIDI sound bank used by the player: FluidR3 by Frank Wen, mono conversion FluidR3Mono by Michael Cowgill, MIT license (see `FluidR3Mono_License.md`).
- `demo-multitrack.mid` — the site's demo song (original piece, free to use).
- `app.esm.js` — the compiled player bundle.
- `steps/`, `og-image.png` — page images.
